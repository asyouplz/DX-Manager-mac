DX Manager GUI preview — first launch

Open DX Manager.app to use the native Mac window. Terminal is not opened.
This local GUI preview is separate from the published terminal edition 2.0.2.

1. Extract the complete ZIP. You can move the whole DX Manager.app to Applications.
2. If macOS blocks it, review System Settings > Privacy & Security > Open Anyway.
   Only approve a package from a source you trust. Do not edit files inside the app.
3. Connect an unlocked Galaxy with USB debugging enabled and approve its RSA prompt.
4. Choose the phone at the top, select DeX or Single window 1–3, and edit its settings.
5. Click Save settings or Start. Start saves this device/mode's settings first.
6. Stop ends the selected mode. Quit DX Manager (Command+Q) stops its sessions and
   waits for cleanup. Keep the phone connected until the app closes.

The app is ad-hoc signed for integrity, without Apple Developer ID/notarization.
Bundled components may need separate approval. It does not change Gatekeeper settings.
Phone controls in this new GUI have not yet been physically tested.
Keyboard settings provide key conversion, F8 capture and a floating mini bar.
Accessibility controls keys; Screen Recording permits capture. Grant only the needed
permissions to DX Manager.app, then restart if macOS requests it.

Settings: ~/Library/Application Support/DX Manager/config/settings.json
Logs: ~/Library/Logs/DX Manager
The optional Start DX Manager.command still opens the separate terminal edition.

한국어

DX Manager.app을 열면 Mac용 설정 창이 뜹니다. Terminal은 열리지 않습니다.
이 GUI 미리보기는 공개된 터미널 버전 2.0.2와 별도입니다.

1. ZIP 전체를 풉니다. DX Manager.app 전체를 응용 프로그램 폴더로 옮길 수 있습니다.
2. macOS가 차단하면 시스템 설정 > 개인정보 보호 및 보안에서 '그래도 열기'를
   확인합니다. 신뢰하는 출처의 패키지만 승인하고 앱 내부 파일은 수정하지 마세요.
3. Galaxy의 잠금을 풀고 USB 디버깅을 켜서 연결한 뒤 RSA 승인을 합니다.
4. 위에서 휴대폰을 선택하고 DeX 또는 단일창 1~3을 선택해 설정합니다.
5. '설정 저장' 또는 '시작'을 누릅니다. 시작 버튼도 해당 기기·모드 설정을 먼저 저장합니다.
6. '중지'는 선택 모드를 종료합니다. Command+Q는 이 앱에서 실행한 세션을 정리하고
   종료합니다. 앱이 닫힐 때까지 휴대폰 연결을 유지하세요.

무결성 확인용 ad-hoc 서명이며 Apple Developer ID·공증은 없습니다.
개별 구성요소도 승인이 필요할 수 있습니다. Gatekeeper 설정은 변경하지 않습니다.
새 GUI의 휴대폰 제어는 아직 실기 검증하지 않았습니다.
키 입력 설정에서 키 변환·F8 캡처·미니바를 조절합니다.
키 제어에는 손쉬운 사용, 캡처에는 화면 기록 권한이 필요합니다.
필요한 권한만 DX Manager.app에 허용하고 macOS가 요구하면 다시 여세요.

설정: ~/Library/Application Support/DX Manager/config/settings.json
로그: ~/Library/Logs/DX Manager
선택형 Start DX Manager.command는 기존 터미널 버전을 엽니다.
